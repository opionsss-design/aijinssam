# 성수동 — 감정 흐름 영상·그림 소재집

[ZIP 다운로드](https://github.com/opionsss-design/aijinssam/raw/refs/heads/codex/seongsu-emotion-assets/output/seongsu-emotion-assets.zip)

- AI 생성 그림 PNG 12장 (836×470)
- 이미지에 느린 확대·축소를 적용한 무음 MP4 12개 (각 8초, 1280×720, 24fps)
- 가사와 장면 연결 안내 CSV 및 제작 안내문

감정 흐름은 익숙한 밤길 → 따뜻한 기억 → 빈자리 → 그리움 → 새벽의 여운입니다. 서울 성수동을 모티브로 한 가상 장면입니다.

영상은 정지 이미지를 바탕으로 만든 편집용 클립입니다. 인물 자체의 동작을 생성한 실사 동영상은 아니며 음원·가사 자막은 포함하지 않습니다.
