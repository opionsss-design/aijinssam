- 고정 화면 무음 MP4 12개 (1920×1080, 24fps, 각 8초)
- 가사와 장면 연결 안내 CSV 및 제작 안내문

화면 확대·축소와 이동을 제거했습니다. 각 영상은 하나의 그림을 8초 동안 고정 표시합니다. 모든 프레임의 해시가 동일한지 확인했습니다.

그림은 기존 생성 원본을 Lanczos 방식으로 확대했습니다. 해상도는 높였지만 새로 촬영한 디테일이 추가되는 방식은 아닙니다.

감정 흐름: 익숙한 밤길 → 따뜻한 기억 → 빈자리 → 그리움 → 새벽의 여운. 서울 성수동을 모티브로 한 가상 장면입니다. 영상에 음원이나 가사 자막은 포함하지 않습니다.
