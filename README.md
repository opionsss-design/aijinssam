# 무역왕의 항해: 세계 무역 탐험대

## 지금 게임을 받는 방법

GitHub에서 이 브랜치의 **Code → Download ZIP**을 누르세요. 압축을 풀고 `play.html`을 Chrome 또는 Edge로 열면 됩니다. `play.html`은 그림과 게임 코드가 모두 포함된 한 파일입니다.

웹 주소로 제공하려면 저장소의 **Settings → Pages → Build and deployment → Source: Deploy from a branch**에서 **game/trade-voyage**, **/(root)**를 선택하고 Save 하세요. 배포가 끝나면 Pages 설정 화면에 실제 사이트 주소가 나타납니다. 이 기능은 저장소 공개 범위와 GitHub 요금제에 따라 사용 가능 여부가 다릅니다.

초등 고학년 사회 교과서 86~101쪽 「국가 간 무역」을 바탕으로 만든 3D 캐릭터 대화와 자유 항해를 결합한 학습 게임입니다. Three.js는 검증한 로컬 파일로 포함하며 실행 중 외부 서버의 이미지·모델·폰트·음원·API를 요청하지 않습니다. 캐릭터와 항구 배경 일러스트는 `assets/`에 포함됩니다.

## 실행

`index.html`을 웹브라우저로 열거나, 이 폴더에서 다음 명령으로 정적 서버를 실행하세요.

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

정적 웹 호스팅에 파일 그대로 올릴 수 있습니다. HTTPS로 호스팅하면 PC·태블릿·스마트폰에서 회원가입 없이 접속할 수 있습니다. 로컬 파일로 실행할 때 브라우저 정책에 따라 저장이 제한될 수 있으므로 수업에서는 정적 웹 호스팅을 권장합니다.

## 프롤로그와 3D 장면

처음 실행하면 **프롤로그 6장면 → 별도 게임 시작 화면 → 직접 항해 → 섬의 NPC와 대화 → 학습 미션** 순서로 진행합니다. 흰 선원 모자·남색 세일러 칼라·빨간 스카프·반바지를 입은 어린 항해사 **하루**, 선장 코트와 모자를 쓴 길잡이 **나루**가 등장합니다. 대화와 시작 화면에는 부드러운 입체감의 동화 일러스트를 사용하고, 미세한 움직임과 화자 강조로 대화를 표현합니다. 항해 화면에는 복장을 맞춘 작은 3D 선원이 배에 탑승합니다. 광택과 과장된 안구·머리카락을 강조하던 기존 캐릭터는 교체했습니다.

프롤로그는 이전/다음, 글 즉시 표시, 건너뛰기를 지원합니다. 한 번 본 뒤에는 다음 실행부터 시작 화면으로 바로 가며, 시작 화면이나 선장실에서 다시 볼 수 있습니다. 섬에 들어가면 하루와 NPC의 2단계 대화를 먼저 듣고 미션에 도전합니다. 객관식 오답 힌트는 NPC의 대사로 표시됩니다.

섬의 해안·지형·건물·나무·항구, 돛단배와 선상 주인공도 Three.js/WebGL로 렌더링합니다. 느린 기기에서는 자동으로 렌더링 해상도와 그림자 부담을 줄입니다. WebGL을 사용할 수 없으면 기존 Canvas 탐험과 단순 캐릭터 표시로 학습 기능을 계속 사용할 수 있습니다.

## 구조

- `index.html`: Canvas 바다, HUD, 미니맵, 조이스틱, 정박 안내와 미션 대화상자
- `style.css`: 반응형 화면, 학습 UI, 인증서 인쇄, 축하 효과
- `missions.js`: 교사가 수정할 섬 위치, 학습 목표, NPC, 문항, 정답, 힌트, 보상, 핵심 개념
- `story-data.js`: 교사가 수정할 프롤로그 화자와 대사
- `assets/sailor-cast.png`: 항해사 하루와 나루의 투명 배경 동화 일러스트
- `assets/harbor-storybook.png`: 같은 색감의 항구 배경 일러스트
- `scene3d.js`: 무광 항해사 모델, 동작, 항구 무대, 섬과 배, 3D 카메라·포인터 좌표 변환, 자동 품질 조절
- `vendor/three.min.js`: Three.js 0.128.0 로컬 런타임 (MIT, `vendor/THREE-LICENSE.txt`). npm 배포본의 SHA-512 integrity를 검증했습니다.
- `game.js`: 프롤로그·시작 화면·NPC 대화 진행, 시간 기반 이동·회전·카메라, 원형 육지 충돌, 항구 감지, Pointer Events 조작, 미션 상태, 보상, 합성 음향, localStorage 저장

## 플레이

- 방향키/WASD 또는 바다를 누르고 있기로 자유 항해합니다. 가상 조이스틱도 마우스·손가락으로 사용할 수 있습니다.
- 미니맵 숫자를 따라 섬의 **아래쪽 항구**로 접근하면 ‘섬에 입장하기’가 나타납니다. E 키도 사용할 수 있습니다.
- 1·2·4·5번 섬은 자유 순서로 도전할 수 있습니다. 3번 섬에서는 의뢰 수락 → 1번 섬에 항해하여 전자 제품과 목재 교환 → 3번 섬으로 돌아와 전달합니다.
- 6번 섬의 종합 미션은 다른 다섯 섬 완료 후 열립니다. 순환 교역 계획과 상호 의존 질문을 해결하면 황금 범선과 인증서를 받습니다.
- 분류 카드는 직접 드래그하거나, 카드를 누른 뒤 창고를 누르세요. 키보드 Tab과 Enter로도 분류할 수 있습니다.
- 보물상자는 한 번당 25코인입니다. 메뉴에서 돛·선체·깃발을 구입할 수 있습니다. 미션 보상은 한 번만 지급됩니다.
- 메뉴에서 배경음악과 효과음을 각각 설정합니다. 오디오는 브라우저의 사용자 상호작용 후 시작됩니다.
- 기록은 같은 사이트의 같은 브라우저에 저장됩니다. 공용 기기에서는 메뉴의 ‘학습 기록 초기화’를 사용하세요. 인증서에는 이름을 입력하고 인쇄/PDF 저장할 수 있습니다.

## 학습 설계

1. 무역의 의미: 국내 거래와 국제 거래, 물건과 서비스 무역 구별
2. 수출입: **우리나라 관점**을 명시하여 분류
3. 무역의 필요성: 자연환경·자원·기술·노동력 차이와 자원 교환
4. 교역 상대: 생산 조건과 필요한 물품 연결
5. 경쟁·공급 문제: 기술과 품질 경쟁, 밀 공급 중단에 대한 협력
6. 상호 의존: 세 나라 모두 필요한 물품을 얻는 교역 계획

가상 국가·섬·갈등 상황은 교과서 개념을 적용한 창작입니다. 통계 수치를 암기하는 문제나 특정 국가의 생산품을 영구적인 사실로 단정하는 문제는 사용하지 않았습니다. 라면·바나나 등의 보상 상품은 게임용 기념품입니다. 3D 모델은 기본 도형으로 직접 만들고 라벨 텍스처도 브라우저 안에서 생성합니다. 외부 리소스 다운로드에 의존하지 않습니다.

## 검증

`tests/game.spec.cjs`는 Playwright와 Chromium이 설치된 환경에서 `node tests/game.spec.cjs`로 실행할 수 있습니다. 실행 전 위 정적 서버를 켜세요. 기본 Chromium 경로는 `/usr/bin/chromium`이며 다른 경우 `CHROMIUM_PATH` 환경 변수로 지정하세요. 배 이동, 충돌, 정박, 미션·운반·보상·중복 방지, 저장 복원, 모바일 조이스틱·분류, 인증서를 검증합니다. 테스트는 브라우저 컨텍스트를 격리하여 실제 학생 기록에 영향을 주지 않습니다.

추가 검사:

```sh
node tests/story.spec.cjs
node tests/resilience.spec.cjs
```

`story.spec.cjs`는 처음부터 프롤로그를 끝까지 진행한 뒤 시작 화면·3D 섬·NPC 대화·오답 힌트를 검사합니다. 모바일 화면, 프롤로그 기록, 외부 네트워크 요청이 없는지, WebGL 미지원 시 대체 실행도 확인합니다. `artifacts/`에는 실제 브라우저 화면을 보관합니다. 소프트웨어 WebGL을 사용하는 테스트는 기기 그래픽 성능에 따라 시간이 걸릴 수 있습니다.

## 배포용 한 파일 만들기

```sh
python3 tools/package.py
```

저장소 상위 폴더에 `무역왕의_항해_3D_바로실행.html`과 `무역왕의_항해.zip`을 만듭니다. 단일 HTML에는 스타일, 모든 게임 스크립트, Three.js와 라이선스, 그림 파일의 base64 데이터가 포함됩니다. 최신 실행 파일은 `무역왕의_항해_동화풍_바로실행.html`입니다. `node tests/bundle.spec.cjs`는 이 파일의 내용을 로컬 문서로 제공해 별도 자원 요청 없이 실행되는지 검사합니다. 관리형 브라우저가 로컬 파일 열기를 제한하는 경우 정적 서버 또는 웹 호스팅으로 실행하세요.

## 확대된 지도와 읽기 쉬운 글자

- 섬의 지름과 건물·항구를 1.5배, 섬 중심 사이 거리를 2.1배로 늘렸습니다. 월드는 5250×4620입니다.
- 배는 1.8배로 확대하고 카메라도 가까이 조정했습니다. 배의 충돌 반경·정박 위치·보물 획득 범위도 함께 맞췄습니다.
- Jua(제목·이름·주요 버튼)와 Gowun Dodum(본문)을 로컬 WOFF2로 포함합니다. Google Fonts 공식 저장소의 원본을 글자 모양 변경 없이 WOFF2로 변환했으며, SIL Open Font License는 `assets/fonts/*-OFL.txt`와 단일 HTML에 포함됩니다.
- PC 제목 아래 설명은 20px, 프롤로그 대사는 25px입니다. 작은 화면에서도 설명을 숨기지 않고 화면 크기에 맞춰 확대합니다.
- 기존 학습 기록을 불러오면 코인·완료 섬·상품·배 꾸미기는 유지하고 배 위치만 새 지도 좌표로 옮깁니다.
- `node tests/size-and-text.spec.cjs`는 다섯 화면 크기의 글꼴·레이아웃과 이전 저장 기록의 복원을 확인합니다.


## 섬마다 다른 학습 배경과 중앙 문제 창

- 시작섬은 항구 마을, 수출입 항구섬은 화물 항구, 자원 부족섬은 목재가 부족한 작업장, 세계 교역섬은 세계 시장, 무역 갈등섬은 협상 광장, 상생의 섬은 협력 정원으로 표시합니다.
- `missions.js`의 `islandBackgrounds`에서 배경을 바꿀 수 있습니다. 그림은 `assets/islands/`에 있으며 단일 실행 파일에도 모두 포함됩니다.
- 대화·문제·결과 창을 PC·태블릿·스마트폰의 화면 중앙에 배치합니다. 긴 문제는 창 안에서 스크롤합니다. 넓은 화면에서는 주인공과 선장을 양옆에 배치하고, 작은 화면에서는 문제에 공간을 확보하면서 안내원 아바타를 표시합니다.
- `node tests/island-scenes.spec.cjs`는 여섯 배경의 실제 이미지 로딩, 네 화면 크기의 중앙 배치, 배경 복원과 WebGL 미지원 대체 동작을 확인합니다. `bundle.spec.cjs`는 새 배경이 오프라인 실행 파일에 포함되는지도 확인합니다.
